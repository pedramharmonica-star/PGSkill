# صندوق ورودی منابع تازه

فایل خام تازه را اینجا بگذارید، با آپلود در GitHub یا commit. بعد به Claude بگویید: **«فایل‌های incoming را پردازش کن»**. هر فایل خوانده و به فرمت درست تبدیل می‌شود، به جای درستش در `skills/` می‌رود، تناقض‌هایش با دانش فعلی گزارش می‌شود، و نسخه portable و فایل‌های `dist/` دوباره ساخته می‌شوند. فایل خام بعد از پردازش به `incoming/processed/` منتقل می‌شود.

> مخزن خصوصی است، ولی رمز، اطلاعات ورود، شماره حساب و اطلاعات شخصی مشتریان را اینجا نگذارید.
