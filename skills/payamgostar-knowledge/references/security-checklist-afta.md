# چک‌لیست الزامات امنیتی افتا (ماتریس تطبیق امنیتی)

منبع: شیت «10-ماتریس تطبیق امنیتی» فایل خودارزیابی، استخراج‌شده از سند الزامات امنیتی برنامه‌های کاربردی تحت شبکه (Quest.PayamGostar.FirstEurasiaeCommerce.V9). نسخه محصول در آن سند 2.7.4 است و سیستم‌عامل و دیتابیس روی Windows Server 2019 و SQL Server 2019 ارزیابی شده‌اند.

داده کامل: `security-checklist-afta.csv` با ستون‌های ردیف، بخش سند، شماره الزام، نوع رکورد، متن الزام، توضیحات، وضعیت در سند، نگاشت به RFP، تصمیم و منبع.

**کاربرد:** پاسخ به ردیف‌های امنیتی RFP و مناقصه‌ها (Log، احراز هویت، رمزنگاری، TLS، SSH، مدیریت نشست و …). «تیک خورده» یعنی شاهد مثبت در سند ارزیابی وجود دارد. «تیک‌نخورده» یعنی در آن سند تأیید نشده است، **نه لزوماً اینکه ندارد**. قابلیت‌هایی که در KB نسخه‌های بعدی آمده‌اند (مثل OTP در 2.8.7) بر این سند مقدم‌اند.

⚠ سند به نام «شرکت تجارت الکترونیک اول اوراسیا» است (تناقض C20).
