# ثبت تناقض‌ها بین منابع، و قاعده موقت

هر ردیف یک تناقض واقعی بین فایل‌های منبع است. ستون «قاعده تا رفع» می‌گوید اسکیل فعلاً چه بگوید. وقتی تیم یک مورد را رفع کرد، فقط همین فایل (و فایل موضوعی مرتبط) به‌روز شود.
اولویت کلی منابع: سند نصب ۱۴۰۴ (زیرساخت) ← **مرکز دانش رسمی و Release Notes** (رفتار محصول، با قید نسخه) ← PGX (معماری و امنیت) ← پاسخ‌های تأییدشده RFI ← کاتالوگ ریزقابلیت ← FAQ ← دک‌ها ← سایت.
