# واژه‌نامه: اصطلاحات پیام‌گستر و معادل‌های RFP

RFPها با واژه‌های عمومی (اغلب انگلیسی) می‌آیند و پیام‌گستر واژه‌های خودش را دارد. قبل از جست‌وجو در کاتالوگ، اصطلاح RFP را با این جدول به اصطلاح پیام‌گستر تبدیل کن.

| اصطلاح RFP / عمومی | اصطلاح پیام‌گستر | کجا |
|---|---|---|
| Customer, Account, Contact, Party | **هویت** (حقیقی / حقوقی)، مخاطب، پرونده | کنسول |
| Anonymous caller / unknown contact | مخاطب ناشناس | کنسول، مرکز تماس |
| Lead | سرنخ | کنسول |
| Opportunity, Deal | فرصت | مدیریت فرصت‌ها |
| Pipeline, Funnel | قیف فروش، مراحل فرصت | فرصت |
| Quote, Proforma | پیش‌فاکتور | مدیریت فروش |
| Invoice | فاکتور | مدیریت فروش |
| Payment, Receipt | دریافت و پرداخت | ماژول دریافت و پرداخت |
| Price book | لیست قیمت | مدیریت لیست قیمت‌ها |
| Record / Entity / Object | **آیتم** (CRM Object)؛ «شخصی‌سازی آیتم‌ها» | کنسول |
| Custom field | فیلد سفارشی / فیلد دلخواه | شخصی‌سازی |
| Workflow, BPM, Process | **چرخه کاری**، فرایند، BPMS | BPMS |
| Inbox, Work queue, Worklist | **کارتابل** (کارتابل من، کارتابل فرایندها) | BPMS |
| Activity (in process) | فعالیت (تخصیص مقدار، چندشرطی، انتظار، اجرای دستورات پایگاه داده، ارسال پیامک …) | BPMS |
| Task | وظیفه، ارجاع وظیفه | کنسول |
| Follow-up, Reminder | پیگیری، یادآوری | کنسول |
| Appointment, Meeting | قرار ملاقات، جلسه | کنسول |
| Case, Ticket, Service request | **درخواست مشتری / تیکت** | تیکتینگ |
| Complaint | شکایت (فرایند شکایات پیشرفته) | تیکتینگ + BPMS |
| Web form, Survey | **فرم عمومی**، فرم نظرسنجی | فرم‌ساز |
| Customer portal / Self-service | **باشگاه مشتریان** | باشگاه |
| Partner / Dealer portal | باشگاه نمایندگان (⚠ ر.ک. conflicts C13) | باشگاه |
| Loyalty, Points, Tiers | امتیازدهی و کلاس‌بندی | باشگاه |
| Campaign | کمپین تبلیغاتی | کمپین‌ها |
| Mass SMS, SMS automation | پیامک هوشمند، رویداد پیامکی، پاسخگوی خودکار | پیامک |
| Merge fields / personalization tokens | **پارامترهای هوشمند** | پیامک، ایمیل، قالب چاپی |
| Print template | قالب چاپی (Word) | فرم‌ساز، فروش |
| CTI, Screen pop | ارتباط با مراکز VoIP/سانترال، **پاپ‌آپ** | مرکز تماس |
| Post-call automation | **رویداد تماس** | مرکز تماس |
| Wallboard, Call center dashboard | داشبورد مرکز تماس | مرکز تماس |
| Barge/Whisper | شنود و نجوا | داشبورد مرکز تماس |
| Role, Permission, RBAC | سمت، چارت سازمانی، مجوز، **حکم سازمانی** | کنسول، حکم |
| Delegate / Substitute | کاربر جانشین | کنسول |
| Report builder | گزارش‌ساز پیشرفته (RDL) | گزارش‌ساز |
| BI dashboard | Power BI، داشبورد مدیریت فروش حرفه‌ای، فرایندکاو | BI |
| Process mining | داشبورد فرایندکاو حرفه‌ای | BI |
| AI assistant | دستیار مدیر / دستیار هوش مصنوعی مدیران | AI |
| ERP / Accounting integration | همگام‌ساز (سینک) مالی | همگام‌ساز |
| Warehouse, Inventory | انبارداری (رسید، حواله، کاردکس، سریال) | انبار |
| Warranty / Authenticity | گارانتی و اصالت کالا | انبار |

## واژه‌های داخلی که در پاسخ به مشتری نباید خام استفاده شوند
- «قبض» (در RFI خدمات پس از فروش) = فرم یا درخواست پذیرش تعمیر؛ در پیام‌گستر «فرم/درخواست + چرخه کاری».
- «داغی» = قطعه معیوب تعویض‌شده که باید به مرکز برگردد.
- «DOA» = Dead on Arrival (خرابی در بدو نصب).
