# نقشه موضوعی قابلیت‌ها

## فهرست
- مسیر استفاده
- حوزه‌های راهنما
- خواندن وضعیت منبع

## مسیر استفاده

ابتدا [گزیده قابلیت‌های تأییدشده و حدود آن‌ها](verified-capabilities.md) را بخوان. برای نسخه‌ها از [یادداشت‌های نسخه](version-notes.md)، برای تبادل اطلاعات از [ماتریس اتصال](integration-matrix.md) و برای API از [راهنمای API](api-guide.md) استفاده کن. سپس با `scripts/search_kb.py` کارت مقاله تخصصی را بیاب و متن رسمی را بخوان. این نقشه، فهرست بسته‌های فروش یا تعهد پشتیبانی نیست.

## خواندن وضعیت منبع

- `article_text_indexed`: متن بخش اصلی مقاله دریافت و نمایه‌سازی شده است.
- `repository_text_indexed`: فایل Markdown مخزن رسمی در commit ثبت‌شده خوانده و نمایه‌سازی شده است.
- `pdf_text_indexed`: متن همه صفحات PDF استخراج شده؛ جدول مبهم RTL نیازمند کنترل بصری است.
- `media_only`: صفحه حاوی رسانه است؛ متن کامل صوت/تصویر در این snapshot وجود ندارد.
- `community_reference`: مرجع کمکی فروم؛ فاقد تأیید قابلیت استاندارد.
- `sample_code_indexed`: نمونه رسمی کد/قرارداد؛ شاهد سازگاری همه نصب‌ها نیست.
- `navigation_only`: صفحه فهرست یا پوسته است و خودش شاهد جزئیات قابلیت نیست.
- `fetch_error`: منبع بازیابی نشده؛ منابع مرتبط مخزن، در صورت وجود، شاهدی جداگانه‌اند.

نمایه واژگانی کارت‌ها جمله و ادعا نیست. از کنارهم‌آمدن دو واژه در آن، رابطه فنی نتیجه نگیر.
