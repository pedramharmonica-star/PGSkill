## واژه‌ها

| عبارت مشتری | واژه‌های جست‌وجوی پیشنهادی | تفکیک لازم |
|---|---|---|
| لید، Lead، مشتری بالقوه | سرنخ، تعیین کفایت، تبدیل سرنخ | سرنخ با فرصت یکی نیست. |
| Contact، Account، پرونده | هویت، شخص، هویت حقوقی، مخاطب | هویت کاربر با کاربر دارای ورود متفاوت است. |
| مشتری ۳۶۰ درجه | پروفایل، سوابق، تاریخچه، هویت | فهرست همه منابع داده و اتصال‌ها را تأیید کن. |
| Pipeline، قیف فروش | فرصت، مراحل، کانبان، تحلیل فرصت | کانبان با پیش‌بینی آماری فروش یکسان نیست. |
| Quotation، Proforma | پیش‌فاکتور، Quote | خرید و فروش را تفکیک کن. |
| Receipt، Payment | دریافت، پرداخت | دریافت مالی با رسید انبار متفاوت است. |
| Workflow، BPMS | چرخه‌کاری، فرآیند، کارتابل، فعالیت، اقدام | از کلید BPMN در سایت انطباق کامل استاندارد استنتاج نکن. |
| صف کار، Inbox | کارتابل، مسئولیت، وظیفه، آیتم در انتظار | صندوق ایمیل با کارتابل فرآیند متفاوت است. |
| Entity، Object | موجودیت، آیتم، زیرنوع | نام نوع پایه و زیرنوع سفارشی را ثبت کن. |
| Custom Field | مشخصه، فیلد اضافه، گروه فیلد، کلید کاربر | کلید فنی با عنوان نمایشی متفاوت است. |
| فرم وب | فرم عمومی، URL، هویت مرتبط | کاربر بیرونی و پرسنل سناریوهای متفاوت دارند. |
| تیکت، Helpdesk | درخواست ایمیلی، درخواست پشتیبانی، شدت، تأثیر، اولویت | SLA و خودکاربودن ارجاع نیازمند شاهد مستقل‌اند. |
| CTI، VoIP، Click-to-Call | مرکز تماس، لاگ، پاپ‌آپ، شنود، نجوا | نوع مرکز و مدل/نسخه را مشخص کن. |
| Marketing Automation | کمپین، برنامه تبلیغاتی، جامعه هدف، ارسال پیام، فرآیند | ارسال گروهی به‌تنهایی اتوماسیون کامل نیست. |
| Loyalty، Portal | باشگاه، مشتریان، نمایندگان، امتیاز، کلاس | دسترسی نماینده و مشتری را مخلوط نکن. |
| BI، Dashboard | گزارش‌ساز، منبع، RDL، گزارش پیشرفته، رایان | داشبورد، دیتاورهاوس و تحلیل پیش‌بینانه یکسان نیستند. |
| API، Webhook | وب‌سرویس، فراخوانی سرویس، SOAP، نام موجودیت انگلیسی | ورودی و خروجی یکپارچه‌سازی را جدا کن. |
| همگام‌سازی دوطرفه | هویت، محصول، پیش‌فاکتور، فاکتور، مرجع ایجاد | جهت ایجاد/ویرایش/حذف ممکن است متفاوت باشد. |
| سریال و گارانتی | انبارداری سریالی، اصالت کالا، سریال محصول | احراز اصالت با مدیریت جامع خدمات گارانتی برابر نیست. |
| HR، استخدام | ATS، رزومه، درخواست نیرو، مصاحبه | ATS، Payroll و حضوروغیاب حوزه‌های متفاوت‌اند. |

## مرزهای معنایی

این نگاشت‌ها ابزار جست‌وجو هستند، نه تضمین برابری مدل داده پیام‌گستر با محصول دیگر. واژه انگلیسی مبهم را با سناریوی مشتری تطبیق بده. برای API، نام کلاس/متد را از سند همان سرویس بردار؛ ترجمه جدول مبنای تولید endpoint نیست.
