# قالب کد پروپوزال (هنوز خالی)

اسکیل پروپوزال اگر این فایل‌ها را اینجا پیدا کند، از آن‌ها شروع می‌کند تا همه پروپوزال‌ها ظاهر یکسان داشته باشند. وگرنه هر بار از صفر می‌سازد و ظاهر سندها کمی با هم فرق می‌کند.

| فایل | نقش |
|---|---|
| `style.css` | قاب صفحه A4، رنگ‌ها، تایپوگرافی، کارت‌ها |
| `icons.py` | آیکن‌های خطی SVG |
| `paginate.js` | صفحه‌بندی جدول نیازمندی‌ها و شماره صفحه |
| `gen.py` | تولید HTML از `rfp.json` |
| `content.py` | متن‌های ثابت (معرفی، روش اجرا، پشتیبانی، گام بعدی) |
| `render.py` | تبدیل HTML به PDF با Playwright |
| `sample/rfp.json` + `sample/PayamGostar-RFP-Response-<Client>.pdf` | یک نمونه کامل و تأییدشده برای مقایسه |

**بهترین منبع:** پوشه کار نهایی پروپوزالی که قبلاً ساخته و تأیید شده (مثلاً دهاب گلوبال ترید). همان فایل‌ها را اینجا بگذارید و داده‌های مخصوص مشتری را از `content.py` پاک کنید.
