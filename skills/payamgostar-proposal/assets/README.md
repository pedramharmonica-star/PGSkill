# دارایی‌های برند پروپوزال (هنوز خالی)

اسکیل پروپوزال اول در این پوشه دنبال لوگو و فونت می‌گردد. تا وقتی این پوشه خالی است، باید هر بار فایل‌ها را پیوست کنید، وگرنه لوگو از روی تصویر بازسازی می‌شود و فونت جایگزین به کار می‌رود.

| مسیر | چه چیزی | وضعیت |
|---|---|---|
| `logo/payamgostar-dark.svg` یا `.png` | لوگوی کامل، نسخه تیره (لوگوتایپ سفید)؛ ترجیحاً SVG رسمی، یا PNG با عرض حداقل ۱۵۰۰px | ⏳ |
| `logo/payamgostar-light.svg` یا `.png` | لوگوی کامل، نسخه روشن | ⏳ |
| `logo/payamgostar-mark.svg` | نماد تنها | ⏳ |
| `fonts/YekanBakh-*.woff2` یا `.ttf` | Yekan Bakh FaNum با وزن‌های 100، 200، 300 (نمایشی) و ترجیحاً 400 و 700 (بدنه). **فقط اگر لایسنس استفاده سازمانی دارید** | ⏳ |
| `brand-guide.pdf` | راهنمای هویت بصری رسمی، اگر وجود دارد | اختیاری |
| `screenshots/*.png` | اسکرین‌شات واقعی و بدون داده مشتری از صفحه‌های کلیدی: داشبورد، پرونده مشتری، کارتابل فرایند، فرم‌ساز، طراح BPMN، گزارش، اپ موبایل، باشگاه | ⏳ |

Vazirmatn (فونت بدنه) آزاد است و هنگام ساخت دانلود می‌شود. لازم نیست اینجا باشد.
